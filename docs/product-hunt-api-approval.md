# Product Hunt API approval checklist

Before any write-capable integration is built or enabled, obtain written confirmation from Product Hunt.

## Request to Product Hunt

**To:** hello@producthunt.com  
**Subject:** Request for Product Hunt API Write Access for TubePilot

Hello Product Hunt team,

I'm the maker of TubePilot, a YouTube Creator OS, and I'm building a small integration for our own Product Hunt launch.

I'd like to request approval for the API write access/scopes required for the intended workflow. Before implementing anything, could you please confirm:

1. Whether our application can be approved for the `public`, `private`, and `write` scopes (or the currently applicable equivalent).
2. Whether the API supports publishing a maker update or comment on our own existing live launch.
3. Whether one scheduled maker update per day is permitted for our own launch, and which documented mutation should be used.
4. Whether any additional approval is required for commercial use.

We will not automate publishing unless the relevant access and the specific operation are explicitly approved. We will use documented API functionality only and will respect Product Hunt's community and anti-spam guidelines.

Thank you,
TubePilot team

## Approval record

Record the approval date, approved scopes, permitted operation, usage limits, and any conditions here. Do not enable publishing based only on an API token or an assumption that write access is available.
